# 社群图片卡片技能

把一篇文章、一条政策、一份招生信息，做成一张可以直接发群的图片卡片。

## 这是什么

一套图片卡片的生成规范：三种尺寸模式 + 三套经过实战的提示词 + 完整的 HTML 模板。AI 拿到本技能后，能按固定规格产出卡片，团队不用每次从零调样式。

## 三种模式，先选一个

| 模式 | 尺寸 | 用在哪 | 交互 |
|---|---|---|---|
| 竖版-精简 | 750px 宽，高度自适应 | 家长群、朋友圈主发图 | PC「复制图片」，手机「保存图片」 |
| 竖版-极简 | 750px 宽，高度自适应 | 只要图，截图或二次加工 | 无按钮 |
| 横版 16:9 | 严格 16:9 | 飞书多维表格、PPT 配图 | 无按钮 |

## 三种用法

**1. 让 AI 直接做（推荐）**

把技能装进 AI 的技能目录后，一句话就能触发：

- 「把这篇文章做成社群图片卡片」
- 「做一个 750px 竖版的元调签约卡片」
- 「把这个政策做成 16:9 横版，放进飞书多维表格」

**2. 手动套提示词**

打开 `references/image-card-prompts.md`，按用途选一套，整段复制，把末尾的 `{{content}}` 换成你的文章内容，交给任意 AI 生成 HTML。

**3. 自己开 HTML 改**

生成的 HTML 直接用浏览器打开：PC 右上角「复制图片」，手机「保存图片」。想改配色，改 `tailwind.config` 里的 `primary / secondary / accent` 三个值。

## 硬性规范（别乱改）

**竖版**
- 固定宽 750px，内容区 690px，左右各 30px
- 主标题 40px / 副标题 32px / 正文 24-26px
- 行高 1.8，正文对比度 ≥ 4.5:1
- 内容 65% + 视觉 35%

**横版 16:9**
- 必须 16:9，不能拉伸
- 主标题 28-32px / 副标题 20-24px / 正文 16-18px
- 行高 1.3-1.4，内容 70% + 视觉 30%
- 所有容器 `overflow-hidden`，文本用 `text-clamp-2/3` 限行

## 内容怎么提炼

- 一张卡片只讲一件事，多个结论拆成系列
- 标题最多两行；副标题一句话说清"跟我有什么关系"
- 竖版留 3-7 个论点、2-3 句引述；16:9 压到 2-4 个论点、1-2 句
- 数字、学校名、时间点必须来自原文，不推算、不凑整
- 强调只标 2-3 处，多了等于没有重点

## 交付前自查

- 尺寸对不对，导出图有没有被拉伸
- 横版内容有没有溢出、被裁
- 竖版核心观点和 CTA 有没有截断
- 文字有没有错别字，数字能不能回溯原文
- 打开导出的 PNG 看，不要只看浏览器预览

## 边界

- 政策、招生、分数线类卡片，数据必须有出处，不确定的别上图
- 不写承诺性表达（包过、保录、百分百），不用绝对化用语
- 卡片是内容载体，不是营销海报：不堆优惠、不叠多层 CTA
